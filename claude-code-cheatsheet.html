Slash Commands

세션 안에서 가장 자주 쓰는 기본 명령

/help

명령이 기억 안 날 때

현재 세션에서 사용 가능한 명령 목록을 다시 엽니다.

/clear

맥락을 비우고 새로 시작할 때

대화 히스토리를 비우고 같은 작업 디렉토리에서 다시 진행합니다.

/compact [instructions]

세션이 너무 길어졌을 때

긴 대화를 짧게 압축해 맥락은 유지하고 토큰 부담을 줄입니다.

/config

설정 확인과 변경

모델, 렌더링, 동작 옵션 같은 구성 변경의 출발점입니다.

/model

모델을 바꾸고 싶을 때

현재 대화에 사용할 모델을 전환합니다.

/permissions

도구 허용 범위를 조정할 때

읽기, 쓰기, 명령 실행 허용 범위를 조절하는 안전 장치입니다.

/review

코드 리뷰가 필요할 때

변경 내용에 대해 리뷰 관점 점검을 요청합니다.

/status

세션/시스템 상태 확인

계정과 환경 상태를 빠르게 다시 점검할 때 씁니다.

/doctor

설치가 이상할 때

Claude Code 설치 상태를 진단합니다.

Slash Commands

The built-in commands people look up most

/help

When you forgot what is available

Reopens the list of available commands in the current session.

/clear

When you want a clean thread

Clears conversation history without leaving the project context.

/compact [instructions]

When the thread gets long

Compresses the conversation while preserving working context.

/config

When you need settings

The main entry point for configuration changes and environment behavior.

/model

When you want a different model

Switches the model used for the current interactive session.

/permissions

When you need to change tool access

Controls the safety envelope for reads, writes, and command execution.

/review

When you want review-mode feedback

Asks Claude Code to inspect your changes from a review perspective.

/status

When you want account or system state

Useful for quickly checking environment and session status.

/doctor

When the installation feels off

Runs health checks against your Claude Code installation.

Project Extension

프로젝트 단위로 기억할 확장 포인트

커스텀 slash commands

.claude/commands/ 아래 Markdown 파일을 두면 프로젝트 명령이 됩니다. 개인용 명령은 ~/.claude/commands/ 에 둡니다.

MCP 프롬프트 명령

MCP 서버가 노출한 프롬프트는 /mcp__server__prompt 형식으로 세션 안에서 바로 실행할 수 있습니다.

hooks 설정

hooks는 .claude/settings.json 또는 사용자 설정 파일에서 관리합니다. 자동 셸 명령 실행이기 때문에 강한 쪽 설정입니다.

메모리 파일

/init 과 /memory 는 프로젝트용 CLAUDE.md 기억을 관리할 때 가장 자주 다시 찾는 흐름입니다.

Project Extension

The extension points worth remembering at project level

Custom slash commands

Put Markdown files in .claude/commands/ for project commands. Personal commands live in ~/.claude/commands/.

MCP prompt commands

MCP prompts become in-session commands using the /mcp__server__prompt format.

Hooks configuration

Hooks are configured through .claude/settings.json or user settings. Treat them carefully because they can execute shell commands automatically.

Memory files

/init and /memory are the main commands to remember when you need to manage project-level CLAUDE.md memory.
